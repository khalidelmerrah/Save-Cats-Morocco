# claude-build-day

Single-file HTML demos. No build, no dependencies.

- `star-system.html`: Halcyra star system exhibit. Units AU / years / solar masses (G = 4 pi^2), star 1.3 M sun, planets feel only the star, fixed-step velocity Verlet with dt = shortest periapsis circular period / 1500.

- `feed-or-dont.html`: retro stealth game, see [[FEAT - Feed or Dont game]].
